# Sistema de Gestión de Tickets de Soporte Técnico

Proyecto Full-Stack desarrollado con Angular, Node.js (Express) y Microsoft SQL Server.

## Requisitos previos
- Node.js (v18 o superior)
- Angular CLI
- Microsoft SQL Server

## Estructura del Proyecto
- `/tickets-angular`: Cliente frontend desarrollado en Angular.
- `/server.js`: Servidor de API REST en Node.js y Express.
- `/db.js`: Módulo de conexión a la base de datos SQL Server.

## Instrucciones de ejecución

### 1. Backend (API REST)
1. Instalar dependencias:
